# How to test HLC?
1. Run the script 
```bash
julia HLC.jl
```

2. Copy `LaserCoordinate1.csv` and  `RobotCoordinate1.csv` from `tests\2025-03-20_14-52-45\test1` to `tests\2025-03-20_14-52-45`.

3. Wait when plots will be updated

4. Do the same with `LaserCoordinate2.csv` and  `RobotCoordinate2.csv` and etc. until ``LaserCoordinate4.csv` and  `RobotCoordinate4.csv`.
